# Perks

Four thresholds per stat, both directions. **24 total.** Held while the stat
is past the line; lost if it drops back. Scoring uses *net* tiers
([doc 05](../05-economy-and-investments.md#why-scoring-is-on-net-tiers)).

| Rule | |
| --- | --- |
| Positive | Pays **only at retirement** (multipliers, bonuses) |
| Negative | Pays **only during the run**, and should be swingy — not a stipend |
| Voice | One sentence. One effect. No sub-conditions |

Numbers in brackets are placeholders. Tune after the tile lists exist.

Notes for later:

- −50 Buds is the only perk that touches another player. If we keep "no
  stolen agency," it should be a recap-visible tax, not a hidden drain they
  can't plan for. Easy to cut if it feels mean.
- Positive Brains currently stacks as pure multiplier, which may double-count
  against the global 30% per net-tier formula. Either perks *are* that
  formula (and these names are flavor), or they're extras on top. **Don't
  author both.** Proposal: the ±% numbers *are* the scoring formula, one
  named perk per threshold, no second hidden multiplier.
