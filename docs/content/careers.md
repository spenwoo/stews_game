# Careers

Copied from `data_files/Life Data File.xlsx` (Careers sheet). That folder is
user-owned — this file is the working copy.

Draw from the pool your education unlocks. Spouse careers use the same list,
same education gate as the player.

**Multiplayer: exclusive.** Each title can be held by only one person in the
lobby (player or spouse). First to the career event gets the better leftover
pool. Layoff / Nepo Baby / Pretender / certain crises return the title. Solo:
ignore exclusivity.

---

## How a career is rolled

The sheet lists a **mid** salary per stage (Base / Promotion 1 / Promotion 2),
in thousands of dollars.

| Rule | |
| --- | --- |
| Stages | Base → Promotion 1 → Promotion 2, after **4** and **8** paydays *in this job* |
| Five possible salaries | Mid −20%, −10%, mid, +10%, +20%, each rounded to the nearest **$10k** |
| On draw | Randomly roll **one of the five** for the current stage. Re-roll when you promote, using that stage's mid |
| Education | `college` = undergrad required. `grad` = undergrad **and** grad school required. Blank = no school required |
| Special perk | One in-run perk for the whole career, active at every stage. Hidden empty cells have none yet |

The spreadsheet note says both "±1 additional salary levels at ±10%" and
"one of the 5 available salaries." Working copy uses the **five-band**
reading (mid ±10% and ±20%). Flag if that was meant to be only three bands.

Example: Investment Banker base mid $100k → rolled from
{$80k, $90k, $100k, $110k, $120k}.

Old 1.5× / 2.2× multipliers are **superseded** — each stage has its own mid.
Payday bands in [doc 05](../05-economy-and-investments.md) need a retune
against this list; mids now run about **$30k–$250k**.

Imposter (Brains −25 A) can, on *initial* career selection only, roll a job
that ignores the education gate. The +10% fire chance then applies while the
perk is active.

## Notes

- **47 careers.** Exclusive-pool math in a 6-player lobby with spouses is
  tight — first to the event still matters, later players may be forced into
  leftovers or (if Imposter) a stolen draw.
- Blank special perks are still to author. The sheet had one perk per career,
  not a separate Senior / Exec perk. Q6 is now "fill the blanks," not "invent
  two per title."
- **Housing-related payments** = cash purchase, mortgage payday, $10k move
  fee, and rental payday. 75% means you pay three-quarters; 50% means half.
- **Health / illness payments** = joint-pain therapy, cancer/Alzheimer's
  payday haircut is *already* a salary cut — this perk stacks as 50% of
  remaining medical cash costs (joint pain $1k → $500; flag cancer/Alzheimer's
  so we don't double-discount salary).
- Podcaster is the only career whose mid **falls** across promotions.
- Truck Driver never changes title or pay — the union perk *is* the career.
- Gang Lacky spelling is as-authored.
