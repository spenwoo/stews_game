# Mid-life crisis deck

Mandatory stop. Draw one. Resolve using current karma: high karma softens or
inverts, low karma makes it sting. Exact thresholds wait on
[Q1](../08-open-questions.md#q1--how-does-karma-work-as-a-separate-resource).
