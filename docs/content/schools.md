# Schools

Copied from `data_files/Life Data File.xlsx` (Schools sheet). That folder is
user-owned — this file is the working copy.

Tuition is paid at the University STOP (undergrad) or at a later grad-school
choice. Loans allowed. **Prudent** (Brains +25 B) cuts loan *interest* 25%,
not the sticker price. **Collegiate** (Brains +25 A) makes Tier 1 draws
slightly more likely.

`grad` = this campus can also be drawn as a **graduate school**.
**Accredited** (Brains +75 A) offers three random grad-capable schools for
$20k.

How Brains / class keys map onto these six undergrad tiers is still a
proposal in
[doc 12](../12-karma-health-housing-start.md#4-youth-stretch-then-college).
Sticker prices below **replace** the old flat $80k / $100k undergrad numbers.
